# Bet House

Static site for GitHub Pages. Firebase stores names, weights, bets, and the two independent scores.

Pages:

- `index.html` — entry
- `player.html` — name gate, Orange and Red tickets, outro
- `master.html` — weights and the book, per market
- `designer.html` — both houses, plus the player QR

Until `js/config.js` has a real Firebase web config, the app runs in preview mode in this browser only.
